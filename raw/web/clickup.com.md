## ClickUp's MCP Server — https://developer.clickup.com/docs/connect-an-ai-assistant-to-clickups-mcp-server

The Model Context Protocol (MCP) is a secure, standardized framework that lets external AI agents interact with ClickUp Workspace data—like tasks, lists, folders, and docs—using natural language.

Public Beta: ClickUp's MCP server is currently in public beta.
ClickUp's MCP Server is available on all plans.

MCP server URL: `https://mcp.clickup.com/mcp`

## What you can do
- Orchestrate task workflows: Manage tasks with assignees, priorities, and due dates across lists and spaces.
- Build executive reports: Create release notes, status updates, and portfolio summaries from tasks and docs.
- Track time: Log time entries and manage timers.
- Answer work questions: Search tasks, docs, and comments for quick answers.
- Collaborate in comments and chat: Summarize threads, extract action items, and post updates.

## Rate limits
1. If Workspace has Everything AI add-on → same as Public API rate limits by plan
2. Without Everything AI add-on:
   - Free Forever: 50 calls per 24 hours
   - Unlimited Plan and above: 300 calls per 24 hours
Rolling 24 hour rate limits from first request. Rate limits cannot be reset.

## FAQ
- OAuth only — no API keys or auth access tokens for MCP
- No deletion tools currently (safety measure)
- Connected Search not available via MCP
- Custom LLM clients supported if JSON-RPC 2.0 over HTTP, OAuth 2.1 with PKCE, MCP spec compliant
