## Quickstart — https://docs.traycer.ai/quickstart.md

Install as Cursor Extension, VS Code Extension, or Windsurf Extension, or via the Traycer GitHub App.

Getting started:
1. Open Traycer from your IDE's command palette or sidebar.
2. Choose your workflow: Plan (single-PR tasks), Phases (complex multi-step), Review (code review), or Epic (specs, tickets, workflow-guided collaboration).
3. Describe your goal.
4. Review the plan or artifacts and iterate until everything matches your intent.
5. Execute the plan or tickets by handing off to your AI coding assistant.
6. Verify results using Traycer's verification process.

## Tasks Overview — https://docs.traycer.ai/tasks/index.md

A Task is an intelligent development workflow that converts high-level requirements into executable plans. Each Task combines:
- Intelligent analysis: Understands your codebase and requirements in context.
- Structured planning: Breaks work into manageable steps or phases.
- Context preservation: Maintains full project understanding across steps.
- Agent integration: Hands off cleanly to your AI coding assistant.

Four modes: Phases (complex features, multi-service), Plan (well-scoped single-PR tasks), Review (comprehensive code review), Epic (specs + tickets + team collaboration).

## Epic Mode — https://docs.traycer.ai/tasks/epic.md

Epic Mode solves preserving human intent from initial idea to implementation. Agents aren't trying to be wrong — they're filling in gaps. Epic Mode captures intent through a system of specs (focused mini-specs per project aspect) combined with structured workflows, actionable tickets, and verification at every stage.

Artifacts come in two types:
- **Specifications (Specs)**: PRD, Tech Doc, Design Spec, API Spec — living documents capturing requirements, design decisions, and technical planning.
- **Tickets**: Actionable work items with acceptance criteria, status (Todo → In Progress → Done), assignee, and agent handoff capability.

Executions track every agent handoff within an Epic, capturing plans, verification results, commits, and status. Smart YOLO for Epic Mode provides intelligent orchestration: dynamically updates specs and tickets, runs executions in parallel, adapts strategy at runtime.

## Verification — https://docs.traycer.ai/tasks/verification.md

Traycer analyzes agent implementation against the original plan and creates categorized review comments:
- **Critical**: Blocks core functionality or plan requirements.
- **Major**: Significant issues affecting behavior or UX.
- **Minor**: Small polish items that don't block functionality.
- **Outdated**: Comments no longer relevant.

Fix options: fix individual comments, fix selected comments, or fix all comments — each sending issues back to the coding agent. Modes: Re-verify (focused, faster) or Fresh Verification (full re-analysis).

## YOLO Mode — https://docs.traycer.ai/tasks/yolo-mode.md

Two flavors:
- **Smart YOLO for Epic Mode**: Intelligent orchestrator that learns from implementation and adapts at runtime — updates specs and tickets, steers plans, runs parallel executions, coordinates verification loops.
- **YOLO for Phases Mode**: Powerful automation using fixed configurations defined upfront for phase-by-phase workflows.

Smart YOLO: evolves the Epic dynamically, runs executions in parallel when safe, steers execution strategy, maintains context throughout the entire execution chain.
