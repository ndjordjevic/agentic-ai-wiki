01What is KIE.ai?basicsplatform

KIE.ai is a unified AI API platform that lets developers access leading video, image, audio, and LLM models through one consistent API. Instead of integrating different providers one by one, you can use KIE to connect to multiple top-tier AI models with a simpler workflow, clearer documentation, and competitive pricing. In many cases, KIE offers access to these models at a lower cost than official pricing, often around 30% lower, and some models may be even more cost-efficient. KIE is built for teams that need reliable, scalable, and cost-effective AI model access in production.

02What models are available on KIE?models

KIE supports a wide range of leading AI models across multiple categories, including video, image, audio, and LLMs. For video generation, KIE supports models such as Seedance 2.0, Veo, Kling, Grok Imagine, and more. For image generation, KIE supports models such as GPT Image 2, Nano Banana, and other advanced image models. For audio generation, KIE supports models such as Suno, ElevenLabs, and other audio-related APIs. For LLMs, KIE supports leading language models including Claude, GPT, Gemini, and more. You can browse the full model list on the model marketplace: <https://kie.ai/market>

03How can I check model pricing?pricing

You can view current model pricing on the KIE pricing page: <https://kie.ai/pricing>Different models may use different billing units, such as per image, per second, per video, or per million tokens. The pricing page shows the applicable billing method for each model.

04Does KIE offer discounts?pricingbilling

KIE’s pricing is transparent and listed publicly. You can check billing and top-up details here: <https://kie.ai/billing>For larger top-ups, KIE may provide bonus credits. For example, a $1,250 top-up includes an additional 10% bonus credits, which makes the effective usage cost approximately 10% lower than the listed price.

05Where can I test models before development?playgroundcredits

Each model page includes a playground where you can test the model before integrating the API. New users also receive 80 free credits for testing, so you can try different models and workflows before starting formal development.

06Where can I find the API documentation?docsintegration

You can find the API documentation here: <https://docs.kie.ai/>The documentation includes API endpoints, request examples, parameters, callback usage, response formats, and model-specific integration details.

07Will I be charged if a task fails?billingtasks

No. Failed tasks are not charged. If a generation task fails, KIE will not charge credits for that failed task. This helps developers test and run production workloads with more confidence, without paying for unsuccessful generations.

08What should I do if I need technical support?support

KIE provides dedicated technical support channels for users. You can join a one-on-one support group through this page: <https://kie.ai/vip-support>From there, you can choose to join via Discord or Telegram. Our support team can help with API integration, task errors, callback issues, billing questions, and production usage problems.

09Is KIE stable enough for production use?reliability

Yes. KIE is designed to support production-level use cases and commercial workflows. We monitor model availability and task performance 24/7, and we continuously optimize routing and backend resources to improve stability. When issues occur, our team works to identify and resolve them as quickly as possible.

10Do KIE credits expire?creditsbilling

No. KIE credits do not expire. Your credits will remain in your account and can be used at any time.

11Can KIE provide invoices? Can company information be added?billing

Yes. KIE supports invoices for business users. After completing a top-up, you can generate an invoice manually from the billing page: <https://kie.ai/billing>Company information can be added during the invoice process.

12How can I check the results of my submitted tasks?taskslogs

You can view your submitted tasks and generation results in Logs:<https://kie.ai/logs>The Logs page allows you to check task records, statuses, parameters, results, and related task details.

13Where can I see recent models and feature updates?modelsupdates

After logging in, you can view recent model releases, pricing updates, and feature changes on the Updates page:<https://kie.ai/api-updates>

14What are the rate limits? Can they be increased?rate limitsintegration

KIE does not set a strict concurrency limit on running tasks. For new request submission, the default limit is 20 new requests every 10 seconds, which equals up to 120 new requests per minute. This is sufficient for most users and production use cases. If you receive a 429 rate limit error, you can contact KIE support to request a higher rate limit. We will review your usage volume and business needs before adjusting the limit.

15What is KIE’s file and log retention policy?logsdata

Media files, including images, videos, and audio, are retained for 14 days. Log data is retained for 2 months. After these retention periods, the data will be permanently deleted. Please download and back up any important files or task logs in advance.

## 7. Asynchronous Task Model

All generation tasks on KIE are asynchronous.A successful request returns:

**HTTP 200**

A `task_id`

Status Verification

A `200 OK` response **only** means the task was successfully **created**. It does **not** mean the task is completed.

To get the final result, you must either:

Provide a callback (webhook) URL in the request, or

Actively poll the "query record info" API using the `task_id`

Up to 20 new generation requests per 10 seconds

Limits are applied per account

Rejected requests will not enter the queue

For most users, this is more than sufficient.

If you consistently hit 429 errors, you may contact support to request a higher limit — approvals are handled cautiously.

## Generation Modes

### Parameter Overview

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `customMode` | boolean | Yes | Controls parameter complexity: `false` (Simple Mode) or `true` (Advanced Mode) |
| `instrumental` | boolean | Yes | Determines vocal presence: `true` (Instrumental only) or `false` (Includes lyrics) |

* * *

## Key Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `prompt` | string | Yes | Text description used to generate music |
| `style` | string | No | Music style instructions (Custom Mode only) |
| `title` | string | No | Title for the generated music (Custom Mode only) |

* * *

### Prompt Character Limits

**Non-Custom Mode**: 500 characters

**Custom Mode (V3_5 & V4)**: 3,000 characters

**Custom Mode (V4_5, V4_5PLUS & V5)**: 5,000 characters

### Style Character Limits

**V3_5 & V4**: 200 characters

**V4_5, V4_5PLUS & V5**: 1,000 characters

### Title Character Limit

**Maximum Length**: 80 characters

## Status Codes & Task States

| Status | Description |
| --- | --- |
| `PENDING` | Task is waiting to be processed or currently generating |
| `TEXT_SUCCESS` | Lyrics/text generation completed successfully |
| `FIRST_SUCCESS` | First track generation completed |
| `SUCCESS` | All tracks generated successfully |
| `CREATE_TASK_FAILED` | Failed to create task |
| `GENERATE_AUDIO_FAILED` | Failed to generate audio |
| `SENSITIVE_WORD_ERROR` | Content filtered due to sensitive words |
