# Mastra

> Mastra is a framework for building AI-powered applications and agents with a modern TypeScript stack. It includes everything you need to go from early prototypes to production-ready applications. Mastra integrates with frontend and backend frameworks like React, Next.js, and Node, or you can deploy it anywhere as a standalone server. It's the easiest way to build, tune, and scale reliable AI products.

# Mastra: TypeScript Framework for AI Agents

Mastra is a TypeScript framework designed to help developers "build AI agents your users actually depend on." The platform enables rapid prototyping and production deployment of AI-powered applications.

## Key Setup Requirements

To begin a Mastra project, developers need:
- A `package.json` file with `{ "type": "module" }`
- Dependencies including `@mastra/core@latest`, `zod@latest`, `typescript@latest`, and `@types/node@latest`
- A configured `tsconfig.json` file with ES2022 target settings

## Tool and Agent Creation

Tools must be created using the `createTool()` function from `@mastra/core/tools`, requiring an `id`, `description`, `inputSchema` (using Zod), and an `execute()` function. As noted in the documentation: "Plain object tool definitions silently fail to execute; tools MUST be defined via `createTool()`."

Agents are instantiated from `@mastra/core/agent` with properties including `id`, `name`, `instructions`, and `model`. Critically, the model should be specified as a string in `provider/model` format (e.g., `openai/gpt-5.5`), not as a provider object.

## Supported Models

Available models include OpenAI's GPT series, Anthropic's Claude variants, and Google's Gemini options. Each provider requires specific environment variables (OPENAI_API_KEY, ANTHROPIC_API_KEY, etc.).

## Framework Integration

Mastra supports integration with Next.js, React, Astro, Express, SvelteKit, Hono, and other frameworks through dedicated guides.

## Use Cases

The framework enables applications ranging from embedded product agents to customer-facing assistants, internal copilots, data analysis tools, content automation, DevOps workflows, and sales automation systems.

# Agents Overview - Mastra Documentation

## Core Concept

Mastra agents are AI-powered systems that "use LLMs and tools to solve open-ended tasks" by reasoning about goals, deciding which tools to apply, and iterating until reaching a final answer.

## Key Setup Requirements

**Model Format**: Models must be defined as strings using `provider/model` format (e.g., `openai/gpt-5.5`), not as provider objects. For OpenAI specifically, use forward slashes, not colons.

**Tool Definition**: Tools must be created using `createTool()` from `@mastra/core/tools`. Plain object definitions will fail silently. Each tool requires an `id`, `description`, `inputSchema` (using Zod), and an `execute()` function.

**Agent Creation**: Instantiate the `Agent` class with required properties including `id`, `name`, `instructions`, and `model`. Tools are passed as an object to the constructor.

**Registration**: Agents must be registered in your Mastra instance at `src/mastra/index.ts` to access shared resources like memory and logging.

## Usage Methods

- **`.generate()`**: Returns full response with `text`, `toolCalls`, `toolResults`, `steps`, and token usage
- **`.stream()`**: Delivers tokens in real time via `textStream` while exposing promises for other data

## When to Use Agents

Use agents "when the task is open-ended and the steps aren't known in advance." For predetermined processes with explicit control flow, use workflows instead.
