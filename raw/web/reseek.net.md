## Save Any Type of Digital Content

Paste a link, drop in a file, or write a note. Reseek pulls out the useful parts automatically so your library stays searchable without extra work.

### Save Any Link

Paste a URL and we fill in the details. Paste a web link and Reseek fetches the page title and description, then saves extra details like preview image, site name, author, and publish date when the page provides them.

- Paste a link to any article or page
- We save the title and page description automatically
- Preview image and site details when available
- Easy to search later from one library

### Notes That Organize Themselves

Write first, tidy up later. Write plain text or markdown notes, paste images into them, and let Reseek turn them into searchable knowledge. If you do not add tags yourself, the app can generate them for you.

- Plain text and markdown notes
- Paste images right inside your notes
- Automatic tags if you want help organizing
- Search across all your notes later

### Save Twitter/X Posts

Paste the post link and we unpack it. Paste an X or Twitter post URL and Reseek pulls in the post text, author, date, and engagement counts. If the post includes images, we can also read text from those images so that content becomes searchable too.

- Post text, author, and post date are saved
- Like, repost, reply, view, and bookmark counts when available
- Attached images and videos are kept in metadata
- Text inside attached images can be read with OCR

### Save YouTube Videos

Paste a video link and we capture the context. Paste a YouTube URL and Reseek saves the video title and description, plus useful details like thumbnail, author, publish date, views, likes, hashtags, and chapters when available.

- Video title and description saved automatically
- Thumbnail and video ID are stored for preview
- Views, likes, author, and publish date when available
- Hashtags and chapters when the source provides them

### Turn Images Into Searchable Text

Upload an image, we read the text. Upload a screenshot, photo, receipt, or scanned page and Reseek extracts the text from it. That text is then saved into your library so you can find it later with search.

- Works for screenshots, receipts, and document photos
- Makes image content searchable
- Also reads text from images attached to saved X posts

### Upload PDFs and Search Them

We read the file page by page. Upload a PDF and Reseek extracts the text plus file details like page count and word count. The app stores PDF pages as searchable content so you can find the right section later.

- Text is extracted automatically after upload
- Page count, word count, and file info are saved
- PDF pages become searchable inside your library
- Useful for papers, reports, invoices, and ebooks
