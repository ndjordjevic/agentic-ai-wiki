## Get Transcript — https://docs.supadata.ai/get-transcript

The Supadata Transcript API retrieves text transcripts from videos on YouTube, TikTok, Instagram, X (Twitter), Facebook, or public file URLs. The service "fetches existing transcript or fall back to AI to create one."

**Core Endpoint:** `GET https://api.supadata.ai/v1/transcript` (requires `x-api-key` header).

**Key Query Parameters:**

| Parameter | Type | Required | Details |
|-----------|------|----------|---------|
| url | string | Yes | Video or file URL to transcribe |
| lang | string | No | ISO 639-1 language code preference |
| text | boolean | No | Returns plain text when true (default: false) |
| mode | string | No | Options: `native`, `generate`, or `auto` |

**Response Types:**
- HTTP 200 (immediate) — plain text: `{content: string, lang: string, availableLangs: string[]}`, or timestamped: `{content: [{text, offset, duration, lang}], lang: string, availableLangs: string[]}`
- HTTP 202 (asynchronous) — `{jobId: string}` for large videos requiring processing

**Polling:** `GET https://api.supadata.ai/v1/transcript/{jobId}`; statuses `queued`, `active`, `completed`, `failed`. Recommended polling interval: every 1 second; results expire after 1 hour.

**Supported formats & limits:** video platforms — YouTube, TikTok, Instagram, X, Facebook. File formats — MP4, WEBM, MP3, FLAC, MPEG, M4A, OGG, WAV (max 1 GB).

**Pricing:** native transcript — 1 credit; AI-generated — 2 credits per minute of video. "Videos longer than 20 minutes will automatically trigger an asynchronous job."

## Web Scrape — https://docs.supadata.ai/web/scrape

The Supadata scraping API extracts content from web pages: "Extract content from any web page using our powerful scraping API."

**Request methods:** JavaScript/Node.js (`@supadata/js` SDK, `supadata.web.scrape()`), Python (`supadata` package), or direct cURL to `https://api.supadata.ai/v1/web/scrape`.

**Parameters:**

| Parameter | Type | Required | Purpose |
|-----------|------|----------|---------|
| url | string | Yes | Webpage URL to scrape |
| noLinks | boolean | No | Controls Markdown link inclusion |
| lang | string | No | Language preference (ISO 639-1 code, default: en) |

**Response:** JSON containing `url`, `content`, `name`, `description`, `ogUrl` (Open Graph metadata), `countCharacters` (content length metric), `urls` (list of discovered links).

Docs guidance: "Respect robots.txt and website terms of service when scraping web content."

**Cost:** 1 credit per scraping request.
