## What DesignMD measures.

What it captures, how the analysis works, and how the output fits into an AI-native workflow.

What is a DESIGN.md?
A structured markdown spec that captures a website's design system — colour tokens, typography, spacing scale, CSS variables, responsive breakpoints, interaction states, and component patterns. Designed to be read directly by AI coding agents such as **Cursor**, **Claude Code**, and **GitHub Copilot**.

How does DesignMD measure a design system?
A structural analysis of the production frontend at the URL you provide — reading the live DOM and CSSOM for CSS variables, computed styles, responsive breakpoints, hover and focus states, and contrast pairs. **Nothing is inferred from screenshots.** The DESIGN.md is generated from the measured data, not from an image of the page.

Can I use DesignMD with Cursor, Claude Code or GitHub Copilot?
Yes. Download the DESIGN.md and drop it into your project as `DESIGN.md` or `AGENTS.md` context. Cursor, Claude Code, Copilot, Windsurf, and any chat-based LLM can read it directly. A dedicated CLI for one-shot integration is in progress.

Is DesignMD free? Do I need an account?
DesignMD is free and unauthenticated. **Five analyses per day** per IP — no signup, no credit card. The quota resets on a rolling 24-hour window.

Is it legal to extract design tokens from a public website?
DesignMD reads only publicly served HTML and CSS — the same data a normal browser receives. The measured tokens function as a structural reference; do not copy brand identity (logos, trademarks, brand-specific imagery), and respect each source site's terms of service.
