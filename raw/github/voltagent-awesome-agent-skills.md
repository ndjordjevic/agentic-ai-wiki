### Skill Quality Standards

- **Description:** Third person, state what the skill does and when to use it. Specific keywords agents can match on.
- **Progressive disclosure:** Top-level metadata under ~100 tokens. Skill body below 500 lines. Load resources on demand.
- **No absolute paths:** Never hard-code machine-specific paths.
- **Scoped tools:** Request only the tools the skill actually needs.

### Security Notice

Skills are curated, not audited. Review skills before use. Recommended tools: Synk Skill Security Scanner, Agent Trust Hub. Skills can include prompt injections, tool poisoning, hidden malware payloads, or unsafe data handling patterns.

### Contributing

Submit new skills via PR. Focus on community-adopted skills published by development teams and proven in real-world usage. Quality over quantity.

### Ecosystem Tools

The companion platform officialskills.sh provides a browsable registry of all listed skills organized by org. VoltAgent's TypeScript agent framework (github.com/VoltAgent/voltagent) is featured as the primary AI agent framework for TypeScript.
