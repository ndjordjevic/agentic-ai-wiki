# BuildPartner.ai

> BuildPartner.ai is a plugin for Claude Code that makes its users better at building. It adds skills for step-by-step guided builds run inside your own project and on-demand expert advice drawn from named expert frameworks, plus a web dashboard for builds, 1:1 coaching, and account management.

For founders and operators using Claude Code. Install the plugin, then type a command in Claude Code. Builds walk one step at a time and fill each step's prompt with your project's real context, so the output is tuned to what you are actually working on rather than a generic tutorial.

Distributed through the Claude Code plugin marketplace. The npm package `buildpartner` provides the MCP server the skills call.

## Install

Run this in a terminal. It adds the marketplace, installs the plugin, and configures the MCP server:

```
curl -fsSL buildpartner.ai/install.sh | bash
```

Then restart Claude Code and type `/buildpartner:build` to start.

No account is required to install. The free plan needs no credit card.

## Skills

Each skill is a command you type inside Claude Code.

- `/buildpartner:build` (premium): Walk through any BuildPartner build live in your terminal. Fills each step's prompt with your project's real context and runs it with you, one step at a time.
- `/buildpartner:expert-advice` (premium): Ask any question. Get matched to the right expert framework: pricing, content, launch, product, and more.
- `/buildpartner:improve-system` (free reviews): Reviews your setup, captures learnings, audits for rot. Keeps your system sharp over time. Reviews are free. A run of your self-improving system uses credits on the free plan.
- `/buildpartner:open-dashboard` (free, unlimited): Open your BuildPartner.ai dashboard in the browser, automatically signed in.

Free skills are unlimited on every plan. Premium skills draw from 5 free credits on the free plan (a build uses 2 credits, an expert question uses 1), then need Pro.
