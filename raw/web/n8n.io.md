## Landing page — https://n8n.io/

n8n is a workflow automation platform designed for technical teams to build AI agents and automations with visual and code-based interfaces. The platform emphasizes transparency, control, and integration capabilities across 500+ services.

**Core Capabilities:**
- Visual workflow builder with code integration (JavaScript/Python)
- 500+ pre-built integrations plus custom API connections
- AI agent building with multi-model support
- Human-in-the-loop controls and guardrails
- Self-hosted and cloud deployment options

**Development Experience:**
- Re-run single workflow steps without full reprocessing
- Real-time input/output visibility
- Native AI evaluation tools
- Git-based version control
- Multi-user collaboration

**Use Cases:**
- IT operations (employee onboarding, ticket enrichment)
- Security operations (incident response, threat intelligence)
- AI agent development and RAG systems
- CRM automation and lead management
- Backend prototyping

**Enterprise Features:**
- SOC 2 and GDPR compliance
- SSO/SAML authentication
- On-premises deployment with Docker
- Audit logging and SIEM integration
- Role-based access control

**Social Proof:**
- 192,600+ GitHub stars (github.com/n8n-io/n8n)
- 4.9/5 rating on G2
- 200,000+ community members
- Case studies from Huel, Vodafone, and Musixmatch

Getting started: Free registration available at app.n8n.cloud; enterprise sales consultation available.
