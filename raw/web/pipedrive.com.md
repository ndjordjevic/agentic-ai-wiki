# Pipedrive REST API v1

"This reference helps you implement the RESTful Pipedrive API. This API uses a JSON format for output and is capable of handling CORS requests." The system is stateless; all requests are validated using an API token obtained from the Pipedrive application.

**60+ endpoint groups including:**
Activities, Deals, Leads, Organizations, Persons, Products, Projects, Tasks, Users, Webhooks, and more.

**Developer Resources:**
- OpenAPI 3 specification files for both v1 and v2 APIs
- Postman integration option for API testing
- Sandbox accounts for testing
- Official API client libraries (Node.js, PHP) plus community libraries (Python, .NET, Ruby)
- Changelog for API updates
