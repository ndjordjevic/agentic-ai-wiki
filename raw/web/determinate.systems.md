## Get started — https://docs.determinate.systems/getting-started/individuals/

Determinate is an end-to-end toolchain for using Nix consisting of Determinate Nix and FlakeHub. Available on macOS, most Linux systems (including SELinux), and WSL.

### Install Determinate Nix

Install via the one-liner or macOS graphical package. For NixOS see the advanced installation guide.

### Log in to FlakeHub

After installing, authenticate with FlakeHub using GitHub account via `determinate-nixd login`. This provides a URL to create a token at https://flakehub.com/token/create. Paste the `flakehub1_...` token when prompted.

### Publish flakes to FlakeHub

Use the `flakehub-push` GitHub Action to publish flakes automatically on each push to main:

```yaml
name: Publish every Git push to main to FlakeHub
on:
  push:
    branches:
      - main
jobs:
  flakehub-publish:
    runs-on: ubuntu-latest
    permissions:
      id-token: write
      contents: read
    steps:
      - uses: actions/checkout@v5
      - uses: DeterminateSystems/determinate-nix-action@v3
      - uses: DeterminateSystems/flakehub-push@main
        with:
          rolling: true
          visibility: private
          include-output-paths: true
```

Initialize a new flake: `nix flake init` or interactively with `fh init`.

## Advanced installation — https://docs.determinate.systems/guides/advanced-installation/

### Install on NixOS

Use the `nixosModules.default` module output from the `determinate` flake:

```nix
{
  inputs.determinate.url = "https://flakehub.com/f/DeterminateSystems/determinate/*";
  inputs.nixpkgs.url = "https://flakehub.com/f/NixOS/nixpkgs/0";

  outputs = { determinate, nixpkgs, ... }: {
    nixosConfigurations.my-workstation = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        determinate.nixosModules.default
      ];
    };
  };
}
```

Then use extra substituters on first switch:

```shell
sudo nixos-rebuild \
  --option extra-substituters https://install.determinate.systems \
  --option extra-trusted-public-keys cache.flakehub.com-3:hJuILl5sVK4iKm86JzgdXW12Y2Hwd5G07qKtHTOcDCM= \
  --flake ... \
  switch
```
