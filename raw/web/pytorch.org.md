## Features — https://pytorch.org/features/
PyTorch enables fast, flexible experimentation and efficient production through a user-friendly front-end, distributed training, and ecosystem of tools and libraries.

**Production Ready with TorchScript:**
```python
import torch
class MyModule(torch.nn.Module):
    def __init__(self, N, M):
        super(MyModule, self).__init__()
        self.weight = torch.nn.Parameter(torch.rand(N, M))
    def forward(self, input):
        if input.sum() > 0:
            output = self.weight.mv(input)
        else:
            output = self.weight + input
        return output
my_script_module = torch.jit.script(MyModule(3, 4))
my_script_module.save("my_script_module.pt")
```

import torch.distributed as dist

## Learn the Basics — https://pytorch.org/tutorials/beginner/basics/intro.html
Most machine learning workflows involve working with data, creating models, optimizing model parameters, and saving the trained models. This tutorial introduces a complete ML workflow in PyTorch.

Tutorial series: Learn the Basics → Quickstart → Tensors → Datasets & DataLoaders → Transforms → Build Model → Autograd → Optimization → Save & Load Model.

PyTorch has two primitives to work with data: `torch.utils.data.DataLoader` and `torch.utils.data.Dataset`. `Dataset` stores the samples and their corresponding labels; `DataLoader` wraps an iterable around the Dataset.

Domain-specific libraries: TorchText, TorchVision, TorchAudio — all include datasets.

## Quickstart — https://pytorch.org/tutorials/beginner/basics/quickstart_tutorial.html
Complete ML workflow walkthrough:

**Working with data:**
```python
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import v2
```

**Creating Models** — Define neural network by inheriting from `nn.Module`; implement layers in `__init__`, forward pass in `forward`; move to accelerator (CUDA, MPS, MTIA, XPU).
```
NeuralNetwork(
  (flatten): Flatten(start_dim=1, end_dim=-1)
  (linear_relu_stack): Sequential(
    (0): Linear(in_features=784, out_features=512, bias=True)
    (1): ReLU()
    (2): Linear(in_features=512, out_features=512, bias=True)
    (3): ReLU()
    (4): Linear(in_features=512, out_features=10, bias=True)
  )
)
```

**Optimizing Model Parameters** — Requires a loss function and optimizer. Training loop: model makes predictions on batches, backpropagates prediction error to adjust parameters.
