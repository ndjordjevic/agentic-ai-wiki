## Docs — https://docs.warp.dev/

Warp is an **open source Agentic Development Environment** that combines a modern, high-performance terminal with powerful agents to help you build, test, deploy, and debug code. Warp's agents are powered by **Oz**, the orchestration platform for running agents locally or in the cloud at scale.

**Warp terminal — key capabilities:**
- Terminal and Agent modes: Switch between a clean terminal and a dedicated conversation view for multi-turn agent workflows
- Modern terminal UX: Cursor movement, block-based navigation, multi-line editing, syntax highlighting, rich completions — built with Rust
- Code editor: File tree, code editor with LSP support, and interactive code review experience
- Third-party CLI agents: Run Claude Code, Codex, and OpenCode with Warp's agent toolbelt

**Oz — cloud orchestration platform:**
- Local agents: Write and refactor code, debug issues, fix errors, run commands, plan and execute multi-step tasks
- Cloud agents: React to events from Slack, Linear, GitHub, or custom webhooks; run on schedules; fan out across repos; full observability

**Unified local + cloud experience:**
- Same agent, anywhere
- Seamless handoff between cloud and local
- Shared context: Warp Drive, Rules, and MCP servers work across both local and cloud agents
- Team collaboration: Share sessions, review actions, steer running tasks

**Open source:** Client is open source under AGPL v3 at `warpdotdev/warp`

**Security:** SOC 2 compliant, Zero Data Retention with all contracted LLM providers

## Local Agents Overview — https://docs.warp.dev/agent-platform/local-agents/overview/

Warp's local agents are interactive agents embedded directly in the terminal. Agents operate with full context from your codebase, Warp Drive, and connected tools, while you stay in control of every action.

**Capabilities covered in docs:**
- Interacting with Agents — manage AI conversations tied to sessions, attach context, continue previous threads
- Agent questions — answer, skip, and configure clarifying questions the Agent asks
- Agent Context — attach images, URLs, files, code blocks, and selections as context
- Model Choice — pick your preferred LLM from a curated set of top models
- Full Terminal Use — let the agent drive interactive terminal apps, seeing live output
- Interactive Code Review — review agent-generated diffs, leave inline comments
- Task Lists — track complex workflows with automatic task lists that update progress
- Web Search — allow agents to search the web for up-to-date information
- Third-party CLI agents — run Claude Code and Codex with Warp's built-in agent toolbelt
- Active AI Recommendations — get proactive fix recommendations based on errors
- Voice — talk to Warp's agent using voice commands

## Cloud Agents / Oz Platform — https://docs.warp.dev/platform/

Cloud agents are autonomous, background agents that run on Warp's cloud infrastructure or your own, triggered by system events, schedules, or integrations like Slack and GitHub.

**When to use cloud agents:**
- React to system events
- Need observability into agent activity across a team
- Need more parallelism than local execution allows
- Want agents to operate continuously as part of engineering infrastructure

**Each cloud agent task includes:**
- Inputs: a prompt plus context from the triggering system
- Execution context: an Environment defining the repo, image, and startup commands
- Lifecycle state: created → running → completed / failed
- Persistent record: status, metadata, and a session transcript

**Deployment models:**
- CLI-only
- Warp-hosted orchestration
- Self-hosted execution (managed worker daemon or unmanaged `oz agent run`)

**Billing:** Requires credits; individual users can run cloud agents with at least 20 credits available. Teams require Build, Max, or Business plan for integrations.

## Agent Capabilities — https://docs.warp.dev/agent-platform/capabilities/

Agent capabilities are the core building blocks defining how Warp's agents operate:

- **Slash Commands** — quick actions and saved prompts accessible by typing `/`
- **Skills** — reusable, scoped instructions that teach agents how to perform specific tasks
- **Planning** — turn agent requests into organized, editable plans that execute step-by-step
- **Task Lists** — track complex workflows with automatic task lists
- **Rules** — define global and project-level guidelines that shape agent behavior
- **Full Terminal Use** — let the agent drive interactive terminal apps
- **Computer Use** — let agents interact with desktop environments (screenshots, clicking, typing)
- **MCP** — connect external data sources and tools via the Model Context Protocol
- **Codebase Context** — semantic indexing of Git-tracked files for agent understanding
- **Agent Profiles & Permissions** — control permissions and autonomy levels
- **Web Search** — allow agents to search the web
- **Inference & providers** — pick the model, bring your own API key, or connect custom inference endpoint
