Four-phase product loop:
- INVENT: Turn ideas into build-ready specifications with AI interviews
- IMPLEMENT: AI-orchestrated code generation and deployment
- INSPECT: Real-time usage analytics and performance tracking
- ITERATE: AI-powered diagnosis and feature recommendations

Two starting paths:
1. Assessment path (existing app): Code Health & Readiness Assessment — discover bugs and technical debt, assess production readiness, convert recommendations into backlog items, fix them yourself or let Agiloop fix them, continue enhancing with INVENT.
2. INVENT path (new app): Discovery Interview → auto-generated specifications → backlog automatically created → code generation with IMPLEMENT → auto-instrumentation with INSPECT → continuously improve with ITERATE.
