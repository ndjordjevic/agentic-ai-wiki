## AI Observability — https://sentry.io/solutions/ai-observability/
# AI and LLM Observability

Agents, LLMs, vector stores, custom logic—visibility can't stop at the model call.

## Full LLM Observability
Track all agent runs, error rates, LLM calls, tokens used, and tool executions. Monitor traffic patterns and duration metrics across your AI-powered features.

## Track Model Costs & Tokens
Compare costs across different models. See token usage breakdown by model, track input vs output tokens, and identify expensive operations.

## Monitor tool execution
See which tools your agents call, their error rates, average duration, and P95 latency.

## Deep Trace Analysis
Dive into individual requests with full prompt and response context. See AI spans with agent invocations, tool executions, token counts, costs, and timing.

## Works with
Vercel AI, OpenAI Agents, Node.js, Next.js, SvelteKit, Nuxt, Astro, Remix, SolidStart, Express, Fastify, NestJS, Hono, Bun, AWS Lambda, Azure Functions, Google Cloud Functions, Electron

## Getting started
Python (OpenAI Agents): `pip install sentry-sdk` + `OpenAIAgentsIntegration()`
JavaScript (Vercel AI): `Sentry.vercelAIIntegration({ recordInputs: true, recordOutputs: true })` with `experimental_telemetry: { isEnabled: true }` on generateText/streamText calls.
