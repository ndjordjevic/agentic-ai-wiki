## Creating your first project — https://vunote.so/help/articles/creating-your-first-project
[![Image 1: Vunote](https://vunote.so/assets/vunote_logo.png)](https://vunote.so/help)

Getting Started

A **project** is the container for a topic, course, campaign, or research thread. It holds videos, structured notes, AI chat context, and documents you generate.

1.   Click **New project** in the sidebar (or from Home / Projects).
2.   Give it a clear name — for example “Biology Midterm” or “Competitor Reviews Q3”.
3.   Confirm to create it.

You’ll open the project **Workspace**, ready to add videos.

On **Home**, paste a YouTube URL or upload a file. Vunote can create (or attach to) a project as part of import so you start watching sooner.

*   Prefer specific names over “Untitled”.
*   One project per course, campaign, or research question keeps Notes and AI Chat focused.
*   Pin important projects from the Projects list so they stay in the sidebar.

*   [Add videos](https://vunote.so/help/articles/uploading-videos-and-urls)

## How GPT-4 Powers Vunote's AI Features — https://vunote.so/blog/how-gpt-4-powers-vunotes-ai-features
## The Stack

Vunote's AI layer sits on top of several foundation models:

| Feature | Model |
| --- | --- |
| Transcription | OpenAI Whisper / AssemblyAI |
| Summaries | GPT-4 Turbo |
| Project Reports | GPT-4 Turbo (128k context) |
| AI Chat | GPT-4 with RAG |
| Frame Analysis | GPT-4 Vision |
| Insight Extraction | GPT-4 + custom prompts |

## Transcript Pipeline

1.   User imports YouTube URL
2.   Audio is extracted and chunked
3.   Whisper transcribes each chunk in parallel
4.   Chunks are stitched with overlap detection
5.   Speaker diarisation applied (AssemblyAI)
6.   Transcript stored with per-segment timestamps

## Summarisation Pipeline

We don't just dump the transcript into GPT-4. Our pipeline:

1.   Extract the transcript
2.   Chunk into semantic sections
3.   Summarise each section
4.   Merge section summaries
5.   Run a final refinement pass for coherence

This approach handles videos of any length reliably.

## RAG for AI Chat

When you chat with a video, we use Retrieval-Augmented Generation:

1.   Your question is embedded
2.   We retrieve the most relevant transcript segments
3.   GPT-4 answers using only those segments as context
4.   Every answer includes the source timestamp

This keeps answers grounded and reduces hallucinations.

## What's Next

We're exploring fine-tuned models for domain-specific vocabulary (legal, medical, engineering) to improve transcript accuracy in technical content.

## Setting Up Your First Vunote Project — https://vunote.so/blog/setting-up-your-first-vunote-project-step-by-step
## Welcome to Vunote

This guide walks you through setting up your first project and getting real value in under 10 minutes.

## Step 1: Create a Project

1.   Click **New Project** from the dashboard
2.   Give it a descriptive name (e.g. _SEO Learning_, _Leadership Development_, _Competitor Research_)
3.   Optional: Add a description for context
4.   Click **Create Project**

## Step 2: Import Your First Video

1.   Inside your project, click **Import Video**
2.   Paste a YouTube URL
3.   Vunote fetches the title, thumbnail, and metadata automatically
4.   Click **Import** to confirm

## Step 3: Transcribe the Video

1.   Open the video
2.   Click **Transcribe** in the top toolbar
3.   Choose a provider (Whisper is recommended for most content)
4.   Wait 30-90 seconds
5.   The full transcript appears in the right panel

## Step 4: Add Notes

While watching or reading the transcript:

*   Click **+** at any moment to add a timestamped note
*   Choose a type: Note, Bookmark, Highlight, or Insight
*   Tag it for easy filtering later

## Step 5: Generate a Summary or Report

*   **For a single video:** Click **Summarize** to get an AI summary
*   **For the whole project:** Click **Generate Report** to get a cross-video synthesis

## You're Done!

Your first AI-powered video notes are ready. Explore the dashboard to search, filter, and export your insights.
