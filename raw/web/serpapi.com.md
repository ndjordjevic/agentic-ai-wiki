# SerpApi

> SerpApi provides a real-time JSON API for accessing structured search engine results from Google, Bing, Baidu, and more. Trusted by Nvidia, Shopify, Perplexity, Adobe, Samsung, KPMG, Ahrefs, Grubhub, AI21 Labs, United Nations, Thomson Reuters, Morgan Stanley, BrightLocal, Experian, Uber, and thousands of other companies.

- Website: https://serpapi.com
- Sign up: https://serpapi.com/users/sign_up
- API: https://serpapi.com/search
- Example: `GET https://serpapi.com/search?api_key=YOUR_API_KEY&engine=google&q=Coffee`
- Supported engines: Google, Apple App Store, Apple Maps, Baidu, Bing, Brave AI Mode, Amazon, DuckDuckGo, eBay, Facebook, Instagram, Naver, OpenTable, Search Index, The Home Depot, Tripadvisor, Walmart, Yahoo!, Yandex, Yelp, YouTube

## Google Search API — https://serpapi.com/search-api.md

**Basic Request Format:**
```
GET https://serpapi.com/search?api_key=YOUR_API_KEY&engine=google&q=QUERY
```

**Core Parameters:**
- Required: `q` (search query, supports Google operators like `inurl:`, `site:`, `intitle:`), `api_key`
- Search configuration: `engine` ("google" default), `device` ("desktop"/"tablet"/"mobile"), `output` ("json"/"html")

**Location Parameters:** `location` (city-level), `uule` (Google-encoded location, cannot combine with location/lat/lon), `lat`/`lon` (requires `gl`), `radius` (meters)

**Localization Options:** `google_domain`, `gl` (two-letter country code), `hl` (two-letter language code), `cr` (country restriction, e.g. "countryFR|countryDE"), `lr` (language restriction, e.g. "lang_fr|lang_de")

**Search Type & Filters:** `tbm` (isch, lcl, vid, nws, shop, pts), `tbs` (advanced search parameters), `safe` ("active"/"off"), `filter` (similar/omitted results, 1 or 0)

**Response Structure:** `search_information` (query metadata and results count), `organic_results` (titles, links, snippets), `knowledge_graph` (entity information), `local_results` (nearby place listings with ratings), `related_searches`, `pagination`

## Search Index API — https://serpapi.com/search-index-api.md

Described as "SerpApi's own, LLM-first web index. Fast, structured JSON for AI grounding, benchmarking, and search automation." Currently in preview.

**Core Functionality:** GET request to `https://serpapi.com/search` with `api_key`, `engine=search_index`, and `q`.

**Key Parameters:**
- Search & pagination: `q` (required), `num` (default 10), `start` (offset)
- Search modes: `safe` ("active" default/"off"); `mode` includes a "deep" setting using "parallel sub-query fan-out" for "more diverse results by decomposing the query into multiple aspects"
- SerpApi-specific: `no_cache` (forces fresh results; cached searches don't count toward monthly limits), `async` (submit now, retrieve later via Searches Archive API), `zero_trace` (Enterprise-only — avoids "storing search parameters, search files, and search metadata"), `output` (json default/raw HTML), `json_restrictor` (reduces payload by filtering output fields)

**Response Structure:** search metadata, organic results (position/title/link/snippet), pagination links, related search suggestions.
